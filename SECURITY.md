# Security policy

## Scope

This repository is a static public website. It has no database, custom authentication, server-side application, or visitor data collection.

Security reports may concern the deployment workflow, dependency or supply-chain configuration, cross-site scripting, unsafe links, exposed credentials, or malicious content in repository automation.

## Reporting

Do not publish an exploitable vulnerability or secret in a public Issue. Contact the repository owner privately through the options on the [s6ygleee GitHub profile](https://github.com/s6ygleee) and include:

- affected file, URL, or workflow;
- impact and reproduction steps;
- suggested mitigation, if known;
- whether the issue is already public.

For ordinary scientific or documentation errors, use the public Issue templates instead.
