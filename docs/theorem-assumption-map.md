# Theorem–assumption map

This map is a public orientation document, not a replacement for the manuscript, Lean declarations, or verification supplement.

| Layer | Public claim | Logical status | Principal dependency or boundary |
|---|---|---|---|
| Node data | A node carries area, modular shape, rotor phase, state, and winding data | Definition/model input | Identification and fermionic-state axioms |
| D4 move system | Finite root counts, partitions, and selected dispersion identities | Finite formal cores | Declared move system and finite completion |
| Level-3 sector | Cusp action and determinant-two extension to S4 | Finite arithmetic construction | Separately specified relation to the D4 source |
| Ordered histories | Right-regular commutant and selected blocks supply finite gauge factors | Finite/representation-dependent | History algebra, block selection, central quotient |
| Four-dimensional carrier | The finite model selects four directions and an oriented temporal split | Finite conditional model | Stability and physical reconstruction remain open |
| Lorentzian spacetime | OS reconstruction yields a Lorentzian interpretation | Conditional | Physical reflection positivity and full OS premises |
| Gauge theory | SU(3)c × SU(2)L × U(1)Y structure appears in retained blocks | Conditional physical interpretation | Source-to-Wilson/continuum bridge |
| Chiral matter | Declared bimodule has quantised charges and finite anomaly cancellations | Finite conditional calculation | Canonicity, continuum representation, family/vacuum choice |
| Effective gravity | Two-derivative Einstein–Hilbert form | Conditional | Independent metric axiom and controlled derivative expansion |
| Poisson source | Unrestricted source produces the canonical finite model | Open | Source selection, transport, action, RG identity, tightness |
| Photon | Physical Wilson U(1) sector is massless | Open hypothesis | Signed/integer Wilson comparison |
| Electroweak sector | Interacting heavy-field correlations have a uniform gap | Open hypothesis | Polymer norm, boundary sewing, cutoff removal |
| Strong sector | Physical four-dimensional SU(3) Yang–Mills has a mass gap | Open hypothesis | Yang–Mills gap plus model-specific universality bridge |
| Phenomenology | Matching and mass relations | Input-dependent outputs | Measured couplings, thresholds, overlaps, and vacuum moduli |

## Interpretation rules

- A Lean proof establishes the encoded statement under the encoded hypotheses.
- Statement coverage does not by itself establish semantic equivalence between prose and code.
- A finite or comparison-model theorem does not automatically transfer to the unrestricted physical source.
- Numerical agreement after matching is not a parameter-free prediction.
- The current Preprints.org manuscript is not peer reviewed.
