# Citation guidance

Use the immutable primary record that matches the work you used.

## Preprint, Version 2

~~~bibtex
@article{lee2026torusnode_v2,
  author  = {Lee, Youngik (Tom)},
  title   = {A Torus-Node Model for Emergent Spacetime, Gravity, and Gauge Structure},
  year    = {2026},
  note    = {Preprint, Version 2; not peer reviewed},
  url     = {https://www.preprints.org/manuscript/202611.0941}
}
~~~

@software{lee2026torusnode_lean_v110,
