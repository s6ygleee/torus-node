Small, reproducible units of research

Research briefs for independent verification

This page is the short route into the Torus-Node model for readers searching for torus theory, emergent spacetime, quantum gravity, gauge structure, or carefully bounded grand unified theory (GUT) and theory of everything (TOE) connections.

Status rule. These are proposed 2–5 page research units, not claims of completed results. Each brief must state its assumptions, distinguish finite mathematics from continuum physics, and link any code or independent reproduction. A GUT or TOE connection is a research context, not a completed unification claim.

Three first targets

Start with a question that can be checked

Use the linked open-problem record for the full background, assumptions, references, and GitHub issue workflow.

TN-OP-03 · open direction

D4 spectral stability

Question: Does the selected four-dimensional carrier and signature survive admissible perturbations, source variation, and coarse-graining?

Deliverable: a precise perturbation class, spectral-gap conditions, finite counterexamples, and a Lean 4 replay of the bounded cases.

Read the full problem · Review formal scope

TN-OP-02 · open direction

Finite reflection positivity

Question: For a declared finite torus-node ensemble, which reflection and observable algebra make the positivity test hold or fail?

Deliverable: an explicit finite calculation, including counterexamples where positivity does not survive. This is a prerequisite question for any continuum reconstruction.

Read the full problem · Discuss a reproduction

TN-OP-04 · open direction

S4 history algebra and gauge representations

Question: Which representations follow canonically from the ordered-history algebra, and which depend on retained-block choices?

Deliverable: a finite representation-theoretic classification with an explicit canonicity test and anomaly constraints. A finite algebraic result is not by itself a physical continuum gauge theory.

Read the full problem · See GUT/TOE context

A low-friction verification path

From search visit to useful research response

  1. Orient

    Read the framework boundary and the linked preprint record. The current manuscript is a preprint and has not undergone peer review.

  2. Reproduce

    Use the separate Lean 4 repository and its archived Zenodo release. Report the exact commit, toolchain, and output.

  3. Challenge or extend

    Open a scoped GitHub Issue for a counterexample or a missing assumption, or use Discussions for an open-ended proposal.
